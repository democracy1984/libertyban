# LibertyBan

> Democratic Telegram moderation bot written in Rust.

**LibertyBan** — Telegram-бот для модерации групп с системой демократического голосования за бан пользователей.

Проект написан на **Rust**, использует **Teloxide** для Telegram API и **SQLite + SQLx** для хранения данных.

> ⚠️ **Work in progress.** Проект находится в активной разработке.

## Основная идея

Вместо того чтобы один администратор принимал решение о бане, участники чата могут начать голосование.

Пример:

```text
Начато голосование за бан @user

Причина: спам

Голосов: 2/5

[ Поддержать бан ]
```

После достижения необходимого количества голосов пользователь блокируется.

Каждый голос может содержать собственную причину, поэтому после завершения голосования бот может показать, почему пользователь был забанен.

## Возможности

### Голосование

* `/report` — начать голосование за бан пользователя
* первый `/report` автоматически становится первым голосом
* один пользователь может проголосовать только один раз в рамках одного vote
* для каждого голоса можно сохранить причину
* количество необходимых голосов настраивается
* для одного пользователя в одном чате не может существовать несколько активных голосований одновременно

### Модерация

* `/ban` — ручной бан пользователя
* `/unban <user_id>` — разблокировка пользователя
* хранение причины и автора ручного бана
* отдельный список заблокированных пользователей

### Роли

В каждом чате существуют две роли:

```text
owner
admin
```

Владелец может:

```text
/giveadmin
/removeadmin
```

Администратор может выполнять модерационные действия, но не может управлять владельцем.

### Настройки

Для чата можно хранить:

```text
required_votes       — сколько голосов необходимо
action_limit         — лимит действий администратора
action_period_hours  — период действия лимита
```

## Архитектура

```text
src/
├── main.rs
├── config.rs
├── commands.rs
└── db.rs

migrations/
└── 0001_init.sql
```

### `main.rs`

Точка входа приложения.

Отвечает за:

* загрузку конфигурации
* инициализацию базы данных
* создание Telegram Bot
* запуск Dispatcher

### `config.rs`

Загружает настройки из `.env`.

### `commands.rs`

Содержит Telegram-команды, проверки ролей и основную логику модерации.

### `db.rs`

Содержит работу с SQLite:

* администраторы
* заблокированные пользователи
* настройки чата
* голосования
* голоса пользователей

## База данных

Основные таблицы:

```text
admins
banned_users
chat_settings
votes
vote_users
```

Связь голосования:

```text
votes
  │
  └── vote_users
          ├── user
          ├── reason
          └── created_at
```

Для одного чата и пользователя допускается только одно активное голосование:

```text
(chat_id, target_user_id)
```

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/democracy1984/libertyban.git
cd libertyban
```

Создать файл `.env`:

```env
TELEGRAM_API_KEY=YOUR_BOT_TOKEN

SQLITE_DB_URL=sqlite://libertyban.db

OWNER_ID=123456789
OWNER_CHAT=-1001234567890

REQUIRED_VOTES=5
ACTION_LIMIT=5
ACTION_PERIOD_HOURS=6
```

### Описание переменных

| Переменная            | Описание                     |
| --------------------- | ---------------------------- |
| `TELEGRAM_API_KEY`    | Token Telegram-бота          |
| `SQLITE_DB_URL`       | Путь к SQLite базе           |
| `OWNER_ID`            | Telegram ID владельца        |
| `OWNER_CHAT`          | ID основного чата            |
| `REQUIRED_VOTES`      | Количество голосов для бана  |
| `ACTION_LIMIT`        | Лимит действий за период     |
| `ACTION_PERIOD_HOURS` | Длина периода лимита в часах |

Запуск:

```bash
cargo run
```

Для production-сборки:

```bash
cargo build --release
```

## Требования к Telegram

Бот должен быть добавлен в группу и иметь права, необходимые для модерации пользователей.

Для голосований бот должен иметь возможность:

```text
банить пользователей
удалять сообщения
отправлять сообщения
редактировать свои сообщения
```

## Roadmap

### Phase 1 — Voting Core

```text
callback query
      ↓
проверка пользователя
      ↓
добавление голоса
      ↓
обновление vote message
      ↓
проверка threshold
      ↓
ban
```

### Phase 2 — Multi-chat

```text
new chat
   ↓
ensure_chat()
   ↓
default settings
   ↓
owner/admin configuration
```

### Phase 3 — Moderation

Планируется добавить:

```text
mute
warnings
temporary bans
moderation history
```

### Phase 4 — Configuration

Все настройки должны конфигурироваться отдельно для каждого чата.

## Design goals

LibertyBan старается придерживаться нескольких принципов:

* простая архитектура
* минимум лишних зависимостей
* данные хранятся в реляционной БД
* критическая логика контролируется базой данных
* moderation rules привязаны к конкретному чату
* действия пользователей должны быть проверяемыми и воспроизводимыми
